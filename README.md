# ChainFeed

Social media platform built on the Proton XPR blockchain. Users earn CFT tokens for posting, commenting, and interacting — the token economy replaces the ad-based model.

Live beta. Real users. Real on-chain transactions.

---

## Background

I've been building this solo for about 18 months. The goal was simple: a social platform where the value generated by user activity goes back to the users, not to advertisers. Everything here — frontend, backend, blockchain integration, games, Android APK — was designed and built by one person.

This repo contains a partial codebase shared for review. Core modules are available under NDA.

---

## What's built

**Social layer**
- Feed, posts, comments, replies, likes, reposts
- Media upload with auto-compression and rotation handling
- Privacy controls, user profiles, story-style content (Chain Flashes)
- Real-time notifications and chat with multimedia support

**Token economy**
- CFT wallet — earn, send, withdraw on-chain
- P2P marketplace for buying and selling CFT
- Direct purchase via USDT, USDC, PayPal
- Staking with configurable reward tiers
- Post marketplace — posts as tradeable digital assets

**Games (play-to-earn)**
Seven integrated games with wallet flows and weekly token rankings: Chain Sniper, Chain Rush, Chain Snake, Chain Wheel, Castle Siege, Abyss Legends (TCG), Chain Defense.

**Chain Events**
Polls, campaigns, and audio events — all with token rewards and on-chain participation tracking.

**Platform**
- Android APK with Proton WebAuth deep-link routing
- Auto-translation (ES ↔ EN)
- Dark/light theme system
- Referral system

## Stack

| | |
|---|---|
| Frontend | Vanilla JS, HTML, CSS |
| Backend | PHP 8, MySQL |
| Blockchain | Proton XPR — `@proton/web-sdk` |
| Auth | Proton WebAuth + email/password |
| Hosting | Hostinger |
| Mobile | Android WebView (`com.chainfeed.app`) |

No frameworks. The decision was intentional — full control over performance and load times on low-end devices, which is most of the target market.
